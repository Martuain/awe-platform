# CAP-003 — Studio Integration

## Purpose
Expose the Brand & Design Direction capability as the next human-reviewable stage in AWE Studio.

## Studio flow
Approved Discovery → Approved Strategy → Generate Design Direction → Review → Approve.

## User-visible artifact
Studio presents:
- source strategy version
- brand attributes
- visual principles
- semantic color direction
- typography direction
- imagery direction
- component direction
- accessibility requirements
- rationale
- approval state

## Product boundary
CAP-003 is a design brief, not a pixel editor or final design-file generator. Exact brand assets, design tokens, image generation, and visual editing remain deferred.
