# CAP-003 — Brand & Design Direction

## Purpose
Translate an approved Website Strategy into a reviewable visual direction before website composition.

## Contract
CAP-003 requires both approved Business Discovery and approved Website Strategy. It produces a versioned Brand & Design Direction artifact.

## Vertical slice
Discovery approved → Strategy approved → Generate Design Direction → Review → Approve.

## Design principles
- Strategy-derived, not arbitrary visual generation.
- Semantic palette before final brand assets exist.
- Accessibility and responsive behavior are design requirements.
- Human approval before downstream composition.
- Immutable approved artifact.

## Initial artifact
- brand attributes
- visual principles
- semantic color palette
- typography direction
- imagery direction
- component direction
- accessibility requirements
- rationale
- source strategy version

## Deferred
- logo generation
- exact color extraction from brand assets
- font procurement/licensing
- design-token package
- visual editor
- image-generation provider
- pixel-level design files

## API
- POST `/api/v1/brand-design/generate?project_id=...`
- GET `/api/v1/brand-design/{project_id}`
- POST `/api/v1/brand-design/{project_id}/approve`

## Validation
A deterministic API end-to-end test proves the dependency chain and approval lifecycle.
