# CAP-002 — Website Strategy

## Objective

Transform approved Business Discovery context into a reviewable strategy for the website that follows.

## Contract

Input: approved CAP-001 `DiscoveryContext`.

Output: `WebsiteStrategy` containing sitemap, page objectives, content strategy, design direction, rationale and source context version.

## Lifecycle

`draft → ready_for_review → approved`

## API

- `POST /api/v1/website-strategy/generate?project_id={id}`
- `GET /api/v1/website-strategy/{project_id}`
- `POST /api/v1/website-strategy/{project_id}/approve`

## Principle

No strategy generation before Business Discovery approval.

## Vertical slice

The first implementation is deterministic and provider-independent. A real model adapter will be introduced behind the existing gateway after the capability contract and evaluation behavior are stable.
