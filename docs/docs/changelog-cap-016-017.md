# Changelog — CAP-016 + CAP-017

## Combined release

### Added
- One-click Studio action to move generated websites through build and validation into Preview.
- Strategy/design traceability checks in generated artifacts.
- Responsive generated-site baseline.
- SEO metadata baseline.
- Improved generated navigation, typography, sections and CTA treatment.

### Changed
- Generation now consumes approved Strategy and Brand & Design Direction alongside the Website Specification.
- Studio presents the executable MVP path as a product workflow rather than separate technical operations.

### Deferred
- Hosted build workers
- Streaming/cancellable builds
- Artifact registry
- Authentication/authorization
- Multi-tenancy
- Additional generated frameworks
